2. 拆解（最小实验设计）
目标：用最小成本验证"DL 多任务优势"是否在本数据上成立，避免先搭空架子。
      维度
      设计
      模型
      1D-CNN（5 主线共享 backbone + 独立 head）
      数据
      AI / 半导体 / 机器人 / AR 光学 / 航空航天，每条 60–120 根 K 线
      特征
      [Open, High, Low, Close, Volume] 5 维
      标签
      二分类：未来 20 日涨幅 > 10% = 1，否则 0
      对照组
      (A) no sharing：每主线独立模型；(B) share all hidden；(C) share first hidden（本项目方案）
      评估
      样本外 alpha + t-statistic + 最大回撤
      时间预算
      1–2 周
  实验执行前细节写入 plan.md；运行过程写入 experiment_001.md。
拆解任务清单（最小实验）
1. 数据准备：历史 K 线 + 二分类标签，前复权 / 停牌 / 涨跌停处理，时间对齐防泄露
2. 1D-CNN baseline：(A) no sharing vs (B) share all vs (C) share first hidden
3. 时序训练：滚动 Walk-Forward，绝不随机 shuffle
4. 样本外验证：t-statistic > 2、alpha、最大回撤
5. Transformer 升级：仅在 baseline 通过后启动

4. 纪律与认知基线
  来源：用户 2026-09-07 学习笔记（最小实验启动前必读避坑清单）
认知基线：神经网络只是工具，七维差距决定表现——同样的网络，输入 / 目标 / 训练 / 链路 / 风控 / 认知 / 市场每一环的取舍，拉开各家量化表现的差距。真正投研 80% 在数据治理、防泄露、时序验证、风控约束、交易成本建模；网络模块只是其中一小部分。

      7. 市场变化
      Alpha 衰减
      统计规律会失效，拥挤加速衰减
强约束（7 条，从 024 沿用）
1. 不立即启动工程，先做最小实验
2. 未经历史回测的阈值不许拍脑袋
3. 每条样本外验证要求 t-statistic > 2
4. 结果不达预期不立项为 027，记入 024.x 作结论
5. 保持 backbone 共享 + head 独立，不重洗 Yato 框架
6. DL 输出必须经 Yato 风控层（002/011/012/018）过滤
7. 不复制 020 教训：跨市场结构前先验证同构（主板 / 创业板 / 科创板不默认共享）
